##  1. DANH MỤC CONTROL

|                                  |                                                                                                                                                                                                                                                                                                                                                                                                                          |                                                                                            |                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| Loại control                     | Mô tả chung                                                                                                                                                                                                                                                                                                                                                                                                              | Mô tả thêm / Minh họa                                                                      | Ghi chú                                                         |
| #### Single line of text         | Ô nhập một dòng.<br> `maxlength` mặc định 255 nếu nghiệp vụ không quy định khác — không cho nhập quá `maxlength`.  <br>Hint mặc định: _"Enter _&lt;tên trường&gt_;"_.  <br>Đang có dữ liệu → hiện nút **X** bên phải để xóa nhanh về trống.  <br>→ Bắt buộc nhập mà bỏ trống → thông báo đỏ **ngay dưới ô nhập**: _"Please enter {field}"_.  <br>→ Sai định dạng → thông báo đỏ ngay dưới ô nhập: _"{field} is invalid"_ | Quy tắc định dạng cho từng trường cụ thể: xem PL-02`                                       | Trường bắt buộc đánh dấu **(*)**                                |
| #### Numeric                     | Chỉ cho nhập ký tự số, **căn phải**.  <br>Dùng dấu phẩy `,` phân cách hàng nghìn.  <br>Mặc định không hiện đơn vị; nếu có thì đặt ở cuối                                                                                                                                                                                                                                                                                 | `7,500` — OK  <br>7.500 — NOT OK                                                           | Số tiền dùng loại này, không dùng `Singlelineoftext`            |
| #### Countdown timer             | Đếm ngược từ một mốc thời gian do server trả về.  <br>Hết giờ → tự chuyển trạng thái theo nghiệp vụ (bật lại ô nhập, bật nút gửi lại mã…)                                                                                                                                                                                                                                                                                | Với OTP: đếm từ `OTP_TTL`; hết giờ mới bật _"Gửi lại mã"_ — xem `PEYE-HT-2026-CFG-01` §1.3 | **Mốc thời gian luôn lấy từ server**, không tính từ đồng hồ máy |
| #### Label                       | Hiển thị văn bản thuần, tối đa 1 dòng.  <br>Nội dung dài hơn khu vực hiển thị → hiện `...` bên phải                                                                                                                                                                                                                                                                                                                      | Không dùng `Label` cho nội dung cần người dùng đọc hết — dùng `Infobox`                    |                                                                 |
| #### Button                      | Nút hành động                                                                                                                                                                                                                                                                                                                                                                                                            | Mỗi màn chỉ có **một** nút chính                                                           | Nút gọi API phải vô hiệu trong lúc đang xử lý                   |
| #### Hyperlink                   | Nút dạng chữ, không viền không nền                                                                                                                                                                                                                                                                                                                                                                                       | Dùng cho hành động phụ: _"Quên PIN?"_, _"Đổi số điện thoại"_                               |                                                                 |
| #### Infobox                     | Khối thông tin. Dùng để giải thích bối cảnh, **không** phải để báo lỗi                                                                                                                                                                                                                                                                                                                                                   | Tối đa 3 dòng                                                                              |                                                                 |
| #### Warningbox                  | Khối cảnh báo. Dùng cho điều kiện người dùng cần biết trước khi hành động                                                                                                                                                                                                                                                                                                                                                | Tối đa 3 dòng                                                                              |                                                                 |
| #### Inlineerror                 | Dòng chữ đỏ **ngay dưới ô nhập** đang vi phạm                                                                                                                                                                                                                                                                                                                                                                            | Là cách báo lỗi mặc định cho lỗi định dạng và lỗi bắt buộc nhập                            | Không dùng popup cho lỗi nhập liệu                              |
| #### Alert                       | Dải thông báo hiện từ trên xuống. Hai dạng:  <br>→ **Thành công**: nền xanh nhạt, tự tắt sau 5 giây. Dùng khi **kết thúc luồng thành công**.  <br>→ **Thất bại**: nền đỏ nhạt, viền đỏ, có nút **X**, **không tự tắt**; ẩn khi người dùng bấm X hoặc thực hiện lại thao tác. Dùng cho lỗi nghiệp vụ / lỗi hệ thống / mất kết nối **khi người dùng vẫn ở lại màn đó**                                                     | Nội dung dài cho xuống tối đa 3 dòng.  <br>Dạng thất bại: nội dung = nội dung của mã lỗi   | Nghiệp vụ mô tả _"hiện thông báo"_ sau -> dùng `Alert`          |
| #### Confirmation                | Hộp thoại giữa màn, có tiêu đề và ít nhất 2 nút, có nút **X** góc phải.  <br>Hai dạng: **Error** _(1 nút Close, tiêu đề "Error")_ và **Confirmation** _(≥ 2 nút, mặc định No/Yes, focus vào No)_                                                                                                                                                                                                                         | Nghiệp vụ mô tả _"hiện thông báo rồi tiếp tục luồng"_ → dùng `Confirmation`                |                                                                 |
| #### Radio card                  | Thẻ lựa chọn có nút tròn, mỗi thẻ một lựa chọn, chỉ chọn được một.                                                                                                                                                                                                                                                                                                                                                       | Dùng cho danh sách lựa chọn ngắn (≤ 5) cần vùng chạm lớn, ví dụ chọn ngôn ngữ              | Danh sách dài hơn dùng `Singlechoicedropdownlist`               |
| #### Single choice dropdown list | Chỉ chọn được 1 giá trị. Mặc định _"Select"_.  <br>Danh sách sắp xếp theo alphabet. <br>Đang có dữ liệu → hiện nút **X** bên phải để xóa nhanh về trống.   <br>→ Bắt buộc nhập mà bỏ trống → _"Please enter {field}"_                                                                                                                                                                                                    |                                                                                            |                                                                 |
|                                  |                                                                                                                                                                                                                                                                                                                                                                                                                          |                                                                                            |                                                                 |

## 2. QUY TẮC THÔNG BÁO

|                                            |                                  |                                   |
| ------------------------------------------ | -------------------------------- | --------------------------------- |
| Tình huống nghiệp vụ                       | Control dùng                     | Vị trí                            |
| Lỗi định dạng, bỏ trống trường bắt buộc    | `Inline error`                   | Ngay dưới ô nhập vi phạm          |
| Lỗi nghiệp vụ chặn luồng, còn ở lại màn đó | `Alert`                          | TTrên cùng màn, tự tắt sau 5 giây |
| Lỗi nghiệp vụ phải rời màn                 | `Confirmation` dạng Error        | Giữa màn                          |
| Cần người dùng xác nhận trước khi tiếp tục | `Confirmation` dạng Confirmation | Giữa màn                          |
| Kết thúc luồng thành công                  | `Alert`                          | Trên cùng màn, tự tắt sau 5 giây  |
| Giải thích bối cảnh, không phải lỗi        | `Infobox`                        | Trong luồng nội dung              |
| Điều kiện cần biết trước khi hành động     | `Warningbox`                     | Ngay trên nút hành động           |
